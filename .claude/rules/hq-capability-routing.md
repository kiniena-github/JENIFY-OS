# JENIFY HQ capability routing

Apply this rule only to capability/tool selection. It does not replace the canonical repository `CLAUDE.md`, Founder gates, Registry, provider identity rules, Universal Operator, tests, or independent review.

## Truth first

- `packages/headquarter/src/registry/capability-stack.ts` is an **approved catalog**, not connection evidence.
- Never say a capability is installed/connected/authenticated merely because it is listed or enabled in project settings.
- Live availability must come from real local/runtime/provider/Connection Center evidence.
- Reference sites (Mobbin, Awwwards, Cosmos, Pinterest, NameThatUI, Skiper UI, Vengeance UI, Animmaster) are references, not trusted connectors.
- Treat community skills/MCPs/installers as untrusted external code until reviewed.
- Never auto-spend, enable a paid plan, use separately metered API billing, or purchase credits. Stop at the applicable Founder spend gate.

## Premium website/UI work

When the task is material website/UI design and the capabilities are genuinely available, prefer this sequence:

1. Reference research as useful: Mobbin / Awwwards / Cosmos / Pinterest / NameThatUI.
2. Design direction: Frontend Design + UI/UX Pro Max.
3. Component search: 21st first; Skiper UI / Vengeance UI only as secondary sources.
4. Animation: Motion and/or GSAP only where motion improves UX and performance permits it.
5. Build with the explicitly routed coding worker; never substitute provider identity.
6. Audit with Refactoring UI + UX Heuristics before claiming design completion.
7. If a repeatedly useful Jenify pattern emerges, use Skill Creator to propose/test a Jenify-owned skill rather than accumulating random third-party instructions.

If a preferred capability is unavailable, continue with the best safe available path and state the limitation; do not fabricate its use.

## Research

NotebookLM MCP is community/experimental. Use it only after real authentication/setup evidence exists and without exposing credentials. If unavailable, use the normal approved research path rather than pretending NotebookLM participated.

## Media and local models

Nano Banana 2, ChatCut, Atoms, Seedance 2, MiniMax H3, Qwen/local models and similar capabilities are optional/on-demand. Availability, license, cost and compute constraints must be checked at execution time. Free/open weights do not mean free compute.

## Legacy names

- `Magic MCP` means current `21st MCP`; do not create a duplicate legacy integration.
- `Framer Motion` means current `Motion` unless an old project specifically depends on the legacy package name.
