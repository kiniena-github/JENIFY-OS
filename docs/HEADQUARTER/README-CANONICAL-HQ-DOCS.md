1. `JENIFY-HQ-BLUEPRINT-ARCHITECTURE.md` — what HQ is and what it must become.
2. `JENIFY-HQ-IMPLEMENTATION-MASTER-PLAN.md` — how HQ is built and in what order.
3. `JENIFY-HQ-CURRENT-STATUS.md` — where implementation stands right now and the next safe action.

The existing detailed documents in this folder remain useful technical references. The three canonical documents above govern the overall product direction and staged implementation plan.
